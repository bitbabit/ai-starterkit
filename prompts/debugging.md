# Debugging Prompt

Help diagnose this issue without guessing.

1. Restate the observed behavior and expected behavior.
2. List the evidence available and what is still unknown.
3. Give the most likely causes, ordered by probability and impact.
4. Propose the smallest diagnostic steps that distinguish the causes.
5. Do not recommend destructive commands or production changes without warning and explicit approval.
6. Fix the root cause with the smallest safe change.
7. Add a regression test or repeatable verification.
8. Report the exact commands run and their results.

Ask for logs/configuration only when necessary; remind the user to redact credentials and personal data.
