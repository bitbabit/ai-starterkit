# Demo and Pitch Coach Prompt

Help create a clear, truthful hackathon presentation based on the working implementation.

Structure:
1. Problem and target user
2. Why the problem matters
3. Solution and core differentiator
4. Live demo of the main workflow
5. Brief architecture and role of AI
6. Evidence of value, evaluation, or time saved if measured
7. Known limitations and next steps

Do not invent metrics, customers, user feedback, model accuracy, or capabilities. Make claims only when supported by the implementation or evidence. Keep the demo resilient: use a known-good input, rehearse restart steps, and prepare a permitted backup if live dependencies fail.
