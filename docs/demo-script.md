# Demo Script

Target duration: 3–5 minutes unless the event specifies otherwise.

## 1. Problem (20–30 seconds)
Who has the problem, and why does it matter?

## 2. Solution (20–30 seconds)
One sentence describing what the application does and its main benefit.

## 3. Live demonstration (2–3 minutes)
1. Start from a clean, known state.
2. Show the main user journey.
3. Use a safe, representative input.
4. Show the result and explain why it is useful.
5. If relevant, show one differentiator such as citations, measurable time saved, or a well-handled failure.

## 4. Implementation and trust (30–45 seconds)
Explain the architecture briefly, where AI is used, how failures are handled, and relevant privacy/security choices.

## 5. Impact and next steps (20–30 seconds)
State the value, current limitations, and the next improvement.

## Backup plan
- [ ] Known-good demo input available.
- [ ] App restart steps verified.
- [ ] Network / model dependency fallback understood.
- [ ] Screenshots or a short recording available if permitted.
- [ ] Presentation file saved in the required location.
